# 電子帳簿保存法のスキャナ保存の要件 — 解像度200dpi・入力期間・タイムスタンプ・検索とスマホ撮影の注意点

**要点**

- 紙で受け取った領収書・請求書は、要件を満たしてスキャン（スマホ撮影を含む）し、同等確認をすれば**紙の原本を廃棄**できる
- 読み取りは **200dpi 相当以上・カラー（赤・緑・青 各256階調）**。A4 で約387万画素が目安
- 入力期間は **おおむね7営業日以内**（早期入力方式）、または事務処理規程を定めて **最長2か月＋おおむね7営業日以内**（業務処理サイクル方式）。過ぎた書類は紙も保存
- 真実性は入力期間内の**タイムスタンプ**、または入力期間内の保存を確認できる**訂正削除の履歴が残るシステム**で確保
- 検索は取引年月日・金額・取引先。ダウンロードの求めに応じれば範囲指定・組合せは不要。**売上高5,000万円以下で検索要件がすべて不要になる特例は電子取引だけで、スキャナ保存にはない**

## スキャナ保存の要件（令和6年1月1日以後に保存するもの）

| 要件 | 重要書類（契約書・請求書・領収書・納品書など） | 一般書類（見積書・注文書・検収書など） |
| :--- | :--- | :--- |
| 入力期間 | 7営業日以内／最長2か月＋7営業日以内 | 制限なし（事務の手続を明らかにした書類が必要） |
| 解像度・階調 | 200dpi 以上・カラー | 200dpi 以上・グレースケール可 |
| タイムスタンプ（または代替） | 必要 | 必要 |
| ヴァージョン管理（訂正削除の履歴） | 必要 | 必要 |
| 帳簿との相互関連性 | 必要 | 不要 |
| 見読可能装置（14インチ以上・4ポイント文字） | 必要 | 必要（白黒可） |
| 検索（日付・金額・取引先） | 必要 | 必要 |

200dpi の画素数の目安は（縦mm ÷ 25.4 × 200）×（横mm ÷ 25.4 × 200）。A4 で約387万、はがき大で約96万画素です。書類は1枚ずつ画面いっぱいに撮ります。
