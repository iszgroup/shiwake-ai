# 電子帳簿保存法のスキャナ保存の要件 — 解像度200dpi・入力期限・訂正削除の履歴・検索要件とスマホ撮影の注意点

**要点**

- 紙で受け取った領収書・請求書は、要件を満たしてスキャン（スマホ撮影を含む）すれば、**紙の原本を捨てて電子データで保存**できる
- 解像度は **200dpi 相当以上**、**カラー（赤・緑・青 各256階調以上）**
- 受け取ってから **おおむね7営業日以内**、または事務処理規程を定めていれば **最長2か月とおおむね7営業日以内** に入力する
- **訂正削除の履歴が残るシステム**（または入力期限内のタイムスタンプ）、帳簿との相互関連性、取引年月日・金額・取引先での検索が必要

## スキャナ保存の主な要件

| 要件 | 内容 |
| :--- | :--- |
| 入力期間 | 早期入力方式: 受領後おおむね7営業日以内／業務処理サイクル方式: 最長2か月＋おおむね7営業日以内（事務処理規程が必要） |
| 解像度・階調 | 200dpi 相当以上、カラー画像（重要書類）。一般書類（見積書・注文書など）はグレースケールも可 |
| 真実性 | 入力期間内のタイムスタンプ、または訂正・削除の履歴が残る（または訂正・削除ができない）システムでの保存 |
| 帳簿との相互関連性 | 仕訳と証憑の画像を、証憑の番号などで相互に確認できる（契約書・領収書などの重要書類） |
| 見読可能性 | 14インチ以上のカラーディスプレイ・カラープリンタで、4ポイントの文字が読めるように出力できる |
| 検索 | 取引年月日・取引金額・取引先で検索でき、日付・金額は範囲指定、2つ以上の項目の組合せで検索できる |

税務職員からのデータのダウンロードの求めに応じる場合、検索要件の一部（範囲指定・組合せ）は不要になります。基準期間の売上高が5,000万円以下の事業者は、ダウンロードの求めに応じれば検索要件はすべて不要です。

## 200dpi はどのくらいの画素数か

200dpi で読み取ったときの画素数の目安（1インチ = 25.4mm、画素数 =（縦mm ÷ 25.4 × 200）×（横mm ÷ 25.4 × 200））:

| 書類の大きさ | 画素数 |
| :--- | ---: |
| A6（105×148mm・はがき大のレシート） | 約96万画素 |
| A5（148×210mm） | 約193万画素 |
| A4（210×297mm） | 約387万画素 |

最近のスマホのカメラ（1,200万画素など）なら、**書類1枚を画面いっぱいに撮れば十分**です。ただし、**何十枚ものレシートを1枚の写真に並べて撮ると、1枚あたりの画素数が足りなくなり**、要件を満たしません。ISZ™ 仕訳AI では、送信前に写真に写っている書類の枚数を見積もり、「1つの証憑には書類を1枚だけ写してください」とお知らせします。

## スマホで撮るときのコツ

- 書類は**1枚ずつ**、画面いっぱいに撮る
- 影や反射が入らない明るい場所で、真上から撮る
- 長いレシートは、全体が1枚に収まらなければ分けて撮り、同じ証憑としてまとめて送る
- 撮影後、金額・日付・登録番号が読めるか拡大して確認する
- 自分で受け取った書類を自分で撮る場合（社長・従業員）は、受領者が署名して撮影する必要はなくなっています（令和4年1月以後）

## 電子取引のデータ保存とは別の制度

メールで受け取った PDF の請求書や、Web からダウンロードした領収書は「電子取引」で、**印刷して紙で保存するのではなく、電子データのまま保存**する必要があります（2024年1月から義務）。スキャナ保存（紙 → 電子）とは別の制度です。詳しくは[電子取引データの保存](denshi-torihiki.md)を参照してください。

## よくある質問

**Q. スマホで撮った領収書の原本は捨ててもよいですか？**
A. 解像度・入力期限・真実性・検索などのスキャナ保存の要件を満たして保存していれば、原本を廃棄できます。要件を満たせないものは紙の原本を保存します。

**Q. 入力期限の「おおむね7営業日」はいつから数えますか？**
A. 書類を受け取った日からです。事務処理規程で業務処理サイクルを定めている場合は、最長2か月とおおむね7営業日以内になります。

**Q. 検索要件は小規模な事業者でも必要ですか？**
A. 基準期間の売上高が5,000万円以下で、税務職員のダウンロードの求めに応じられるようにしていれば不要です。
