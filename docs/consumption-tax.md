# 消費税の計算方法（2026年版）— 税込・税抜、インボイスの端数処理、2割特例・3割特例・簡易課税

**要点**

- 税率は **標準税率 10%**（国税 7.8%・地方 2.2%）と **軽減税率 8%**（国税 6.24%・地方 1.76%。飲食料品・新聞）
- 税込金額に含まれる税額 = 税込金額 × 10/110（軽減 8/108）
- インボイスの消費税額の端数処理は、**1つの請求書につき税率ごとに1回**
- 納付税額 = 売上の消費税額 − 仕入の消費税額（一般課税）。簡易課税はみなし仕入率、2割特例は売上の税額の20%、3割特例（個人事業者・令和9〜10年分）は30%

## 税込・税抜の換算

| 計算 | 式 | 例（10%） |
| :--- | :--- | :--- |
| 税込 → 税額 | 税込 × 10 ÷ 110 | 1,100円 → 100円 |
| 税込 → 税抜 | 税込 − 税額 | 3,300円 → 3,000円 |
| 税抜 → 税込 | 税抜 × 1.1 | 1,000円 → 1,100円 |

軽減税率 8% なら、税込 1,080円 → 税抜 1,000円・税額 80円です。端数（1円未満）の処理は、切捨て・四捨五入・切上げのどれでもよく、継続して同じ方法を使います。

## インボイス（適格請求書）の端数処理

適格請求書に書く消費税額は、**請求書ごとに、税率ごとの合計額から1回だけ**端数処理します。品目ごとに端数処理して合計する方法は認められていません。

例: 税抜 333円の品物（10%）が3つ → 合計 999円 × 10% = 99.9円 → **99円**（切捨て）、税込 1,098円

## 申告の納付税額

申告書は次の順で計算します。

1. **課税標準額** = 税率ごとの税込課税売上 × 100/110（軽減 100/108）、**千円未満切捨て**
2. **消費税額（国税）** = 課税標準額 × 7.8%（軽減 6.24%）
3. **控除対象仕入税額**
   - 一般課税（積上げ計算）: 仕入の税額の合計 × 78/100
   - 簡易課税: 売上の消費税額 × みなし仕入率
   - 2割特例: 売上の消費税額 × 80%
   - 3割特例: 売上の消費税額 × 70%
4. **差引税額** = 2 − 3、**百円未満切捨て**
5. **地方消費税** = 差引税額 × 22/78、百円未満切捨て

### 例: 税込売上 1,100万円（10%）

課税標準額 1,000万円 × 7.8% = 売上の消費税額（国税）780,000円

| 方法 | 控除 | 納付税額（国税＋地方） |
| :--- | :--- | :--- |
| 一般課税（仕入の税額 40万円） | 312,000円 | **600,000円** |
| 簡易課税（第5種・50%） | 390,000円 | **500,000円** |
| 2割特例 | 624,000円 | **200,000円** |
| 3割特例（個人事業者・令和9〜10年分） | 546,000円 | **300,000円** |

### 簡易課税のみなし仕入率

| 事業区分 | 主な業種 | みなし仕入率 |
| :--- | :--- | :--- |
| 第1種 | 卸売業 | 90% |
| 第2種 | 小売業、農林漁業（飲食料品） | 80% |
| 第3種 | 製造業、建設業、農林漁業（飲食料品以外） | 70% |
| 第4種 | 飲食店業など | 60% |
| 第5種 | サービス業、金融・保険業、運輸通信業 | 50% |
| 第6種 | 不動産業 | 40% |

2種類以上の事業を営む場合は、原則計算と「1種類の事業で75%以上」「2種類の事業で75%以上」の特例計算のうち、控除額が最も大きいものを選べます。

### 2割特例・3割特例

- **2割特例**: インボイス制度を機に免税事業者から適格請求書発行事業者になった事業者（基準期間の課税売上高1,000万円以下など）は、令和5年10月1日から**令和8年9月30日**までの日の属する課税期間について、納付税額を売上の消費税額の**2割**にできます。個人事業者は令和8年分が最後です
- **3割特例**: 令和8年度税制改正で、**個人事業者**に限り、**令和9年分・令和10年分**の申告で納付税額を売上の消費税額の**3割**にできるようになりました（基準期間の課税売上高1,000万円以下など。法人は対象外）
- どちらも事前の届出は不要で、確定申告書に適用を受ける旨を書くだけです

## 中間申告の回数

直前の課税期間の確定消費税額（国税）で決まります。

| 直前期の消費税額（国税） | 中間申告 |
| :--- | :--- |
| 48万円以下 | 不要 |
| 48万円超 400万円以下 | 年1回（6か月分） |
| 400万円超 4,800万円以下 | 年3回（3か月分ずつ） |
| 4,800万円超 | 年11回（1か月分ずつ） |

確定申告の期限（法人は課税期間の末日の翌日から2か月以内）と延長の特例は、[法人の申告・納付期限](shinkoku-kigen.md)を参照してください。

## よくある質問

**Q. 税込価格から消費税額を出すには？**
A. 10%なら 税込 × 10/110、8%なら 税込 × 8/108 です。税込 1,100円なら 100円です。

**Q. 一般課税・簡易課税・2割特例はどれが有利ですか？**
A. 売上と仕入の税額によります。上の例（税込売上1,100万円・サービス業）では、2割特例 20万円 < 3割特例 30万円 < 簡易課税 50万円 < 一般課税 60万円 です。仕入や設備投資が多い年は一般課税が有利になることがあります。

**Q. 3割特例は法人も使えますか？**
A. 使えません。個人事業者の令和9年分・令和10年分が対象です。

**Q. インボイスの端数処理は品目ごとにしてもよいですか？**
A. できません。1つの請求書につき、税率ごとに1回です。
