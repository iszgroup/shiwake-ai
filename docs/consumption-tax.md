# 消費税の計算方法（2026年版）— 税込・税抜、納付税額、2割特例・3割特例・簡易課税

→ **完全版（計算例・よくある質問・出典付き）: [消費税の計算方法（2026年版）— 税込・税抜、納付税額、2割特例・3割特例・簡易課税の比較](https://shiwake.isz.ai/guide/shohizei/?utm_source=github&utm_medium=referral)**

**要点**

- 標準税率 10%（国税 7.8%・地方 2.2%）、軽減税率 8%（国税 6.24%・地方 1.76%）。税込金額の消費税額は 税込 × 10/110（8/108）
- インボイスの消費税額の端数処理は、1枚の請求書につき税率ごとに1回
- 納付税額: 課税標準額（千円未満切捨て）× 7.8% − 控除対象仕入税額 → 百円未満切捨て。地方消費税はその 22/78（百円未満切捨て）
- 2割特例は 2026年9月30日を含む課税期間まで（個人事業者は令和8年分まで）。3割特例は令和8年度税制改正で創設、個人事業者の令和9年分・令和10年分だけ（法人は不可）
- 3割特例は「みなし仕入率70%の簡易課税」と同じ税額。卸売業・小売業は簡易課税、サービス業などは3割特例が有利になりやすい

## 方法ごとの納付税額（税込売上1,100万円・10%・サービス業・仕入の消費税額40万円）

| 方法 | 控除対象仕入税額 | 納付税額（国税＋地方） |
| :--- | ---: | ---: |
| 一般課税 | 312,000円 | 600,000円 |
| 簡易課税（第5種・50%） | 390,000円 | 500,000円 |
| 2割特例 | 624,000円 | 200,000円 |
| 3割特例（個人事業者・令和9〜10年分） | 546,000円 | 300,000円 |

## 簡易課税のみなし仕入率

| 事業区分 | 主な業種 | みなし仕入率 |
| :--- | :--- | ---: |
| 第1種 | 卸売業 | 90% |
| 第2種 | 小売業、農林漁業（飲食料品） | 80% |
| 第3種 | 製造業、建設業、農林漁業（飲食料品以外） | 70% |
| 第4種 | 飲食店業など | 60% |
| 第5種 | サービス業、金融・保険業、運輸通信業 | 50% |
| 第6種 | 不動産業 | 40% |

中間申告は、直前の課税期間の消費税額（国税）が48万円超で年1回、400万円超で年3回、4,800万円超で年11回です。
