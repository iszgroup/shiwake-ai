**要点**

- 中小法人がほぼ毎年使う別表は **一・二・四・五(一)・五(二)**。交際費（十五）・減価償却（十六）・欠損金（七(一)）・所得税額控除（六(一)）などを必要に応じて追加
- 作る順番: **決算の確定 → 明細の別表（十五・十六など）→ 別表四（所得）→ 別表一（税額）→ 別表五(二)・五(一) → 検算 → 地方税・内訳書・概況書**
- 添付書類: 決算書、**勘定科目内訳明細書（①〜⑯）**、**法人事業概況説明書**。地方税は都道府県に **第六号様式**、市町村に **第二十号様式**
- 期限は事業年度終了の日の翌日から **2か月以内**。定款の定めなどで **1か月延長**できるが、利子税がかかる
- 資本金1億円超の法人などは **e-Tax が義務**。税理士が代理送信すれば、法人の電子署名は不要

## 別表四と別表五(一)の検算

> 期首現在利益積立金額合計（別表五(一) 31①）＋ 別表四の留保所得金額（52②）− 中間分・確定分の法人税・地方法人税・防衛特別法人税・道府県民税・市町村民税 ＝ 差引翌期首現在利益積立金額合計（31④）

例: 8,400,000 ＋ 6,600,000 − 1,284,000 ＝ 13,716,000（事業税は差し引く額に含めない）

## 主な別表

| 別表 | 内容 |
| :--- | :--- |
| 一（次葉を含む） | 所得金額・法人税額・地方法人税額・防衛特別法人税額の計算 |
| 二 | 同族会社等の判定 |
| 四 | 所得の金額の計算（当期利益 ＋ 加算 − 減算） |
| 五(一) | 利益積立金額・資本金等の額 |
| 五(二) | 租税公課の納付状況 |
| 七(一) | 欠損金の損金算入（青色欠損金は10年繰越） |
| 十五 | 交際費等の損金算入 |
| 十六(一)(二)(七)(八) | 減価償却（定額法・定率法）・少額減価償却資産・一括償却資産 |
