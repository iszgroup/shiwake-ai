# インボイスの登録番号（T番号）の確認方法と経過措置（80%→70%控除）・少額特例

→ **完全版（計算例・仕訳例・よくある質問・出典付き）: [インボイス制度の実務 — 登録番号の確認、経過措置（80%→70%）、少額特例と仕訳](https://shiwake.isz.ai/guide/invoice/?utm_source=github&utm_medium=referral)**

**要点**

- 登録番号は「T」＋13桁。法人は「T＋法人番号」で、先頭1桁はチェックディジット（9 −（後ろ12桁を右から奇数桁×1・偶数桁×2 で合計し、9で割った余り））。登録の有無は国税庁の適格請求書発行事業者公表サイトで確認する
- 登録番号のない事業者（免税事業者など）からの仕入は、2026年9月30日まで80%、**2026年10月1日から70%** だけ控除できる（令和8年度税制改正）。割合は課税仕入れの日（引渡し・役務完了の日）で判定
- 2026年10月1日以後に開始する課税期間から、1つの免税事業者等からの仕入が年1億円（税込）を超える部分には経過措置を使えない（改正前は10億円）
- 基準期間の課税売上高1億円以下などの事業者は、税込1万円未満の仕入ならインボイスがなくても全額控除できる（少額特例・2029年9月30日まで。1回の取引の合計で判定）

## 経過措置（登録番号のない事業者からの仕入）

| 課税仕入れを行った日 | 控除できる割合 |
| :--- | ---: |
| 2023年10月1日〜2026年9月30日 | 80% |
| 2026年10月1日〜2028年9月30日 | **70%** |
| 2028年10月1日〜2030年9月30日 | 50% |
| 2030年10月1日〜2031年9月30日 | 30% |
| 2031年10月1日〜 | 0% |

控除できる額 = 支払対価（税込）× 10/110 × 70%（最後に1回だけ端数処理）。例: 2026年10月23日に税込11,000円（10%）→ 700円を仮払消費税等にし、残り300円は費用に含める。

## 70%控除の仕訳で注意すること

- 月締めの請求書（例: 9月21日〜10月20日分）は、納品日ごとに80%と70%に分けて仕訳する。9月に始まり10月に完了した役務は全体が70%
- 税抜経理では控除できない30%を費用・資産の取得価額に含めるため、備品の10万円基準や交際費の1人1万円基準を超えることがある（例: 免税事業者から税込107,800円のパソコン → 取得価額100,940円）
- 簡易課税・2割特例の事業者は、継続適用を条件に相手を問わず10/110を仮払消費税等にできる。経過措置の仕入を税込のまま費用にする方法も認められている（国税庁 No.6375）
- 期中に10/110で計上し決算で差額を雑損失にした場合、経費は申告調整不要、減価償却資産・期末在庫に係る部分は申告調整が必要（国税庁 消費税経理通達関係Q&A 問6〜問9）
