# 勘定科目の一覧と仕訳の例 — 領収書の仕訳・税抜経理・会議費と交際費（1人1万円）

**要点**

- 仕訳は「**借方（左）に費用・資産の増加、貸方（右）に支払手段**」。借方と貸方の合計は必ず一致する（貸借一致）
- 税抜経理では、本体と**仮払消費税等**に分けて記帳する
- 取引先との飲食は、**1人当たり1万円以下なら会議費**（交際費から除かれる飲食費。2024年4月1日以後の支出）

## よく使う勘定科目

| 勘定科目 | 領収書の例 |
| :--- | :--- |
| 旅費交通費 | 電車・バス・タクシー、出張の宿泊、駐車場、高速道路 |
| 通信費 | 携帯電話、インターネット回線、切手、宅配便 |
| 消耗品費 | 文房具、10万円未満のパソコン周辺機器、日用品 |
| 会議費 | 打合せの飲食（1人1万円以下）、会議室 |
| 交際費 | 取引先との会食（1人1万円超）、贈答品、慶弔 |
| 新聞図書費 | 書籍、新聞、有料の情報サービス |
| 支払手数料 | 振込手数料、各種手数料、税理士・司法書士の報酬 |
| 地代家賃 | 事務所・店舗の家賃、月極駐車場 |
| 水道光熱費 | 電気、ガス、水道 |
| 広告宣伝費 | Web 広告、チラシ、販促物 |
| 支払報酬 | 外注のデザイン・原稿料（[源泉徴収](withholding-tax.md)の対象になることがある） |
| 租税公課 | 収入印紙、固定資産税、自動車税（法人税等は除く） |
| 福利厚生費 | 健康診断、社内の慶弔、全員参加の社内行事 |
| 車両費 | ガソリン、車検、自動車保険 |

科目の使い分けは事業や事務所の方針で違います。最終的な判断は顧問税理士にご確認ください。

## 領収書の仕訳の例

### 例1: 文房具 3,300円（10%・登録番号あり）を現金で購入（税抜経理）

| 借方 | 金額 | 貸方 | 金額 |
| :--- | ---: | :--- | ---: |
| 消耗品費 | 3,000 | 現金 | 3,300 |
| 仮払消費税等 | 300 | | |

### 例2: 登録番号のない店で 22,000円（10%）の備品を購入（2026年10月・経過措置70%）

| 借方 | 金額 | 貸方 | 金額 |
| :--- | ---: | :--- | ---: |
| 消耗品費 | 20,600 | 現金 | 22,000 |
| 仮払消費税等 | 1,400 | | |

消費税相当額 2,000円のうち 70%（1,400円）だけを仮払消費税等にし、残り 600円は本体に含めます（[経過措置](invoice.md)）。借方合計 22,000円 = 貸方合計 22,000円で貸借が一致します。

## 会議費と交際費の分かれ目

取引先などとの飲食費は、**1人当たりの金額が1万円以下**（2024年3月31日までの支出は5,000円以下）なら交際費から除き、会議費などにできます。

1人当たりの金額 = 飲食費の合計（税込経理なら税込、税抜経理なら税抜）÷ 参加人数

- 例: 取引先と2人で 18,000円 → 1人 9,000円 → **会議費**
- 例: 取引先と2人で 30,000円 → 1人 15,000円 → **交際費**
- 社内の人だけの飲食（社内飲食費）は対象外
- 飲食の年月日、参加者の氏名・関係、人数、金額、店名を書いた書類の保存が要件

なお、中小法人（資本金1億円以下）は、交際費のうち年800万円までを損金にできます（定額控除限度額）。

## よくある質問

**Q. 取引先との飲食はいくらまで会議費にできますか？**
A. 2024年4月1日以後の支出は、1人当たり1万円以下です（それより前は5,000円以下）。

**Q. 免税事業者の店で買った物の仕訳は？**
A. 2026年10月1日以後は、消費税相当額の70%だけを仮払消費税等にし、残りは本体の費用に含めます。

**Q. 税理士への報酬の勘定科目は？**
A. 支払手数料または支払報酬が一般的です。個人の税理士への支払は源泉徴収（10.21%）の対象です。
