# 勘定科目の一覧と仕訳の例 — 領収書の仕訳・税抜経理・会議費と交際費（1人1万円）

→ **完全版（計算例・よくある質問・出典付き）: [勘定科目の一覧と仕訳の例 — 領収書の仕訳・会議費と交際費の違い（1人1万円）](https://shiwake.isz.ai/guide/kanjo-kamoku/?utm_source=github&utm_medium=referral)**

**要点**

- 仕訳は **借方（左）に費用・資産の増加、貸方（右）に支払手段や負債・収益**。借方と貸方の合計は必ず一致します
- 税抜経理では本体と**仮払消費税等**に分けます。登録番号のない相手からの仕入は、2026年10月1日から消費税相当額の **70%** だけを仮払消費税等にします（9月30日までは80%）
- 取引先などとの飲食は、**1人当たり10,000円以下なら交際費等から除けます**（2024年4月1日以後。判定は税抜経理なら税抜、税込経理なら税込）。超えると全額が交際費等です
- パソコンなどは **10万円未満は消耗品費**。中小企業者等は **40万円未満**（2026年4月1日以後の取得）まで全額を損金にできる特例があります

## よく使う勘定科目

| 勘定科目 | 領収書の例 |
| :--- | :--- |
| 旅費交通費 | 電車・バス・タクシー、出張の宿泊、駐車場、高速道路 |
| 消耗品費 | 文房具、10万円未満のパソコン・周辺機器、日用品 |
| 会議費 | 打合せの飲食（1人1万円以下）、会議の弁当、貸会議室 |
| 交際費 | 取引先との会食（1人1万円超）、贈答品、慶弔 |
| 支払報酬料 | 税理士・司法書士などの報酬（個人への支払は[源泉徴収](withholding-tax.md)） |
| 租税公課 | 収入印紙、固定資産税、自動車税（法人税等は除く） |

## 仕訳の例（税抜経理・2026年10月）

| 取引 | 借方 | 貸方 |
| :--- | :--- | :--- |
| 文房具 3,300円（登録番号あり）を現金で | 消耗品費 3,000 ／ 仮払消費税等 300 | 現金 3,300 |
| 登録番号のない店で 22,000円（経過措置70%） | 消耗品費 20,600 ／ 仮払消費税等 1,400 | 現金 22,000 |
| 取引先と3人で 33,000円（1人10,000円・税抜） | 会議費 30,000 ／ 仮払消費税等 3,000 | 現金 33,000 |

33,000円・3人は、税込経理なら1人11,000円で交際費等です。最終的な判断は顧問税理士にご確認ください。
