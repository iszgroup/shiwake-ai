# 減価償却の計算方法 — 定額法・200%定率法・少額減価償却資産（令和8年4月から40万円未満）・一括償却資産

**要点**

- 法人の法定償却方法は、器具備品・車両などは **200%定率法**、建物・建物附属設備・構築物・ソフトウェアは **定額法**
- 取得価額 **10万円未満**は全額経費（消耗品費）、**20万円未満**は一括償却資産（3年で均等）も選べる
- 中小企業者等（青色申告）は、**30万円未満**の資産を全額経費にできる（年合計300万円まで）。**令和8年4月1日以後の取得は40万円未満**に拡大
- 事業に使い始めた年度は、使った月数で按分（月の途中でも1か月）。最後は備忘価額1円を残す

## 取得価額による判定

| 取得価額 | 処理 |
| :--- | :--- |
| 10万円未満 | 消耗品費などで全額損金 |
| 10万円以上 20万円未満 | 一括償却資産（3年で均等に償却）または通常の償却 |
| 20万円以上 40万円未満（令和8年3月31日までの取得は30万円未満） | 中小企業者等の少額減価償却資産の特例で全額損金（年300万円まで） |
| それ以上 | 通常の減価償却 |

例: 取得価額 35万円のパソコン → 2026年3月31日の取得なら通常の減価償却、**2026年4月1日の取得なら少額減価償却資産の特例**（中小企業者等）で全額損金にできる

## 定額法

毎年の償却額 = 取得価額 × 定額法の償却率（耐用年数ごと。1 ÷ 耐用年数を小数点以下3位に切り上げ）

例: 120万円・耐用年数6年（償却率 0.167）→ 毎年 200,400円

## 200%定率法

毎年の償却額 = 期首帳簿価額 × 定率法の償却率（= 2 ÷ 耐用年数）

その額が **償却保証額（取得価額 × 保証率）** を下回った年からは、**改定取得価額 × 改定償却率**で均等に償却します。

| 耐用年数 | 償却率 | 改定償却率 | 保証率 |
| ---: | ---: | ---: | ---: |
| 4年 | 0.500 | 1.000 | 0.12499 |
| 5年 | 0.400 | 0.500 | 0.10800 |
| 6年 | 0.333 | 0.334 | 0.09911 |
| 8年 | 0.250 | 0.334 | 0.07909 |
| 10年 | 0.200 | 0.250 | 0.06552 |
| 15年 | 0.133 | 0.143 | 0.04565 |

### 例: 100万円・耐用年数5年

償却保証額 = 1,000,000円 × 0.10800 = 108,000円

| 年 | 期首帳簿価額 | 計算 | 償却額 |
| ---: | ---: | :--- | ---: |
| 1 | 1,000,000 | × 0.4 | 400,000 |
| 2 | 600,000 | × 0.4 | 240,000 |
| 3 | 360,000 | × 0.4 | 144,000 |
| 4 | 216,000 | 216,000 × 0.4 = 86,400 < 償却保証額 108,000 → 216,000 × 0.5 | 108,000 |
| 5 | 108,000 | 216,000 × 0.5（備忘価額1円を残す） | 107,999 |

## よくある質問

**Q. 少額減価償却資産の特例はいくらまで使えますか？**
A. 中小企業者等（青色申告）が、令和8年4月1日以後に取得した40万円未満（それより前は30万円未満）の資産に使えます。年合計300万円が上限です。

**Q. 200%定率法の改定償却率に切り替えるのはいつですか？**
A. 期首帳簿価額 × 償却率 が 償却保証額（取得価額 × 保証率）を下回った年からです。100万円・5年なら4年目からです。

**Q. 月の途中で買った資産の初年度の償却額は？**
A. 年間の償却額を、事業に使い始めた月からの月数（月の途中でも1か月）で按分します。
