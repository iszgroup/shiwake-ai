# 減価償却の計算方法 — 定額法・200%定率法・少額減価償却資産（令和8年4月から40万円未満）・一括償却資産

**要点**

- 法人の法定償却方法は、器具備品・車両・機械は **200%定率法**、建物・建物附属設備・構築物・ソフトウェアは **定額法**
- 定率法は「期首帳簿価額 × 償却率」が **償却保証額（取得価額 × 保証率）** を下回った年から「改定取得価額 × 改定償却率」に切替え。最後は備忘価額1円
- 期中に使い始めた資産は、初年度を **使い始めた月から期末までの月数 ÷ 12** で按分（月の途中でも1か月）
- 10万円未満は全額損金、20万円未満は一括償却資産（**事業年度の月数 ÷ 36**）も選べる
- 中小企業者等（青色申告・従業員400人以下）は、**令和8年4月1日以後の取得は40万円未満**（それより前は30万円未満）を全額損金にできる（年合計300万円まで・令和11年3月31日まで）
- 償却資産申告（固定資産税）は1月1日現在の資産を1月31日までに。一括償却資産は対象外、少額減価償却資産の特例を使った資産は対象

## 取得価額による判定（法人）

| 取得価額 | 処理 |
| :--- | :--- |
| 10万円未満 | 全額損金（消耗品費など） |
| 10万円以上 20万円未満 | 一括償却資産（3年で均等）、通常の償却、または下の特例 |
| 10万円以上 40万円未満（令和8年3月31日までの取得は30万円未満） | 中小企業者等の少額減価償却資産の特例で全額損金（年300万円まで・別表十六(七)） |
| それ以上 | 通常の減価償却 |

| 耐用年数 | 償却率 | 改定償却率 | 保証率 | 定額法の償却率 |
| ---: | ---: | ---: | ---: | ---: |
| 4年 | 0.500 | 1.000 | 0.12499 | 0.250 |
| 5年 | 0.400 | 0.500 | 0.10800 | 0.200 |
| 6年 | 0.333 | 0.334 | 0.09911 | 0.167 |
| 8年 | 0.250 | 0.334 | 0.07909 | 0.125 |
| 10年 | 0.200 | 0.250 | 0.06552 | 0.100 |
| 15年 | 0.133 | 0.143 | 0.04565 | 0.067 |
