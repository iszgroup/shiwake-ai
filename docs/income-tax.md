# 所得税と年末調整の計算方法（令和8年分）— 給与所得控除・基礎控除・年収の壁

**要点**

- 令和8年分は**給与所得控除の最低額74万円**（収入220万円以下）、**基礎控除104万円**（合計所得489万円以下）。令和8年12月1日施行で、**12月の年末調整から**反映（11月までの毎月の源泉徴収は変わらない）
- 所得税 = 課税所得（1,000円未満切捨て）× 税率 − 控除額。年税額は **× 102.1%**、100円未満切捨て
- 配偶者・扶養親族の所得要件は合計所得 **62万円以下**（給与だけなら年収136万円以下）。19歳以上23歳未満は年収197万円まで特定親族特別控除。勤労学生は合計所得 **89万円以下**
- 社会保険の106万円の賃金要件は **2026年10月1日に撤廃**。扶養の130万円（19〜22歳は150万円）は変わらない
