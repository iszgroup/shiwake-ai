# 法人の申告・納付期限の一覧（2026年版）— 法人税・消費税・源泉所得税・法定調書・償却資産・算定基礎届・年度更新

**要点**

- 法人税・地方法人税・消費税・法人住民税・事業税の確定申告と納付は、**事業年度（課税期間）終了の日の翌日から2か月以内**
- 法人税は「申告期限の延長の特例」で原則**1か月延長**できる。消費税も、法人税の延長特例を受ける法人は届出で**1か月延長**できる。**延長した期間には利子税**がかかる
- 源泉所得税は**支払った月の翌月10日**まで。常時10人未満の事業者は納期の特例で **7月10日・翌年1月20日**
- 法定調書・源泉徴収票・給与支払報告書・償却資産申告は **1月31日**まで
- 算定基礎届は **7月1日〜7月10日**、労働保険の年度更新は **6月1日〜7月10日**
- 国税の期限が土日・祝日・年末年始に当たるときは、その翌日が期限
- 納付が期限に遅れると**延滞税**がかかる（国税。2026年は納期限の翌日から2か月以内 **年2.8%**、2か月を超える部分 **年9.1%**）

## 決算に関する期限（法人）

| 手続 | 期限 | ポイント |
| :--- | :--- | :--- |
| 法人税・地方法人税の確定申告・納付 | 事業年度終了の日の翌日から2か月以内 | 3月決算なら5月31日 |
| 法人税の中間申告 | 事業年度開始の日以後6か月を経過した日から2か月以内 | 前期の法人税額 × 6 ÷ 前期の月数 が10万円以下なら不要 |
| 消費税・地方消費税の確定申告・納付 | 課税期間の末日の翌日から2か月以内 | 中間申告の回数は直前期の税額で決まる（[消費税の計算](consumption-tax.md)） |
| 法人住民税・事業税の申告・納付 | 事業年度終了の日の翌日から2か月以内 | 提出先は都道府県・市町村 |

### 申告期限の延長の特例

- **法人税**: 定款の定め等により、事業年度終了の日の翌日から2か月以内に決算の定時総会が招集されない常況にある法人は、「定款の定め等による申告期限の延長の特例の申請書」を出すと、申告期限が原則1か月延長されます（会計監査人を置いている場合などは延長月数の指定を受けられます）。申請は適用を受けようとする事業年度の終了の日までに行います
- **消費税**: 法人税の申告期限の延長の特例を受ける法人が「消費税申告期限延長届出書」を出すと、消費税の確定申告期限が1か月延長されます（令和3年3月31日以後に終了する事業年度から）
- **納付**: 延長されるのは申告の期限で、延長した期間には**利子税**がかかります。実務では本来の期限までに見込みの税額を納める（見込納付）ことが多いです
- **期限を過ぎた納付**: 法定納期限の翌日から納付の日までの日数に応じて**延滞税**がかかります（2026年は2か月以内 年2.8%、2か月超 年9.1%）。一部納付や修正申告の場合も含めて、[延滞税の計算ツール](https://shiwake.isz.ai/tools/entaizei/?utm_source=github&utm_medium=referral)で計算できます

## 源泉所得税・住民税の特別徴収

| 手続 | 期限 |
| :--- | :--- |
| 源泉所得税（原則） | 給与・報酬を支払った月の翌月10日 |
| 源泉所得税（納期の特例） | 1月〜6月分 → 7月10日、7月〜12月分 → 翌年1月20日 |
| 住民税の特別徴収（原則） | 給与から差し引いた月の翌月10日 |
| 住民税の特別徴収（納期の特例） | 6月〜11月分 → 12月10日、12月〜翌年5月分 → 6月10日 |

源泉所得税の納期の特例は、給与の支給人員が常時10人未満の事業者が税務署に申請して使います。対象は給与・退職手当と、税理士・弁護士・司法書士などの報酬に限られ、原稿料・デザイン料などは毎月の納付です。計算方法は[源泉徴収税額の計算](withholding-tax.md)を参照してください。

## 年末調整と1月の提出物

| 手続 | 期限 | 提出先 |
| :--- | :--- | :--- |
| 年末調整 | その年最後の給与を支払うとき | — |
| 年末調整後の12月分の源泉所得税 | 翌年1月10日（納期の特例は1月20日） | 税務署 |
| 源泉徴収票の交付 | 翌年1月31日 | 従業員 |
| 法定調書・法定調書合計表 | 翌年1月31日 | 税務署 |
| 給与支払報告書 | 翌年1月31日 | 従業員の住所地の市区町村 |
| 償却資産申告（1月1日現在の資産） | 1月31日 | 資産のある市町村（東京23区は都税事務所） |

法定調書は、種類ごとに前々年の提出枚数が**30枚以上**なら e-Tax などでの提出が義務です（令和8年12月31日以前に提出するものは100枚以上）。

| 手続 | 期限 |
| :--- | :--- |

## よくある質問

**Q. 3月決算の法人税の申告期限は？**
A. 5月31日です。土日・祝日に当たるときは翌日になります。延長の特例を受けていれば、原則6月30日です。

**Q. 申告期限を延長すれば、納付も遅らせてよいですか？**
A. 延長した期間には利子税がかかります。本来の期限までに見込額を納めておけば、利子税はかかりません（見込額が不足した部分を除く）。

**Q. 納期の特例を受けると、外注先の源泉所得税も半年ごとになりますか？**
A. 対象は給与・退職手当と税理士・弁護士・司法書士などの報酬だけです。デザイン料・原稿料などは翌月10日までに納めます。
