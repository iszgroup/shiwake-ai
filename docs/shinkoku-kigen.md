# 法人の申告・納付期限の一覧（2026年版）— 法人税・消費税・源泉所得税・法定調書・償却資産・算定基礎届・年度更新

**要点**

- 法人税・地方法人税・法人住民税・事業税・消費税の確定申告と納付は、**事業年度（課税期間）終了の日の翌日から2か月以内**
- 延長の特例で法人税は原則**1か月延長**、消費税も届出で1か月延長。延長した期間は**利子税（2026年は年1.3%）**
- 源泉所得税は**翌月10日**。常時10人未満は納期の特例で **7月10日・翌年1月20日**（給与・退職手当・士業の報酬に限る）
- 法定調書・源泉徴収票・給与支払報告書・償却資産申告は **1月31日**。法定調書の e-Tax 等の義務は**2027年1月提出分から30枚以上**
- 期限が土日・祝日・12月29日〜1月3日なら翌日。延滞税は**2026年 年2.8%（2か月以内）・年9.1%（2か月超）**

## 主な期限

| 手続 | 期限 |
| :--- | :--- |
| 法人税・消費税などの確定申告・納付 | 事業年度終了の日の翌日から2か月以内（3月決算は5月31日） |
| 法人税の中間申告（前期の税額×6/前期の月数が10万円超） | 開始の日以後6か月を経過した日から2か月以内（3月決算は11月30日） |
| 消費税の中間申告 | 前期の消費税額（国税）48万円超で年1回、400万円超で年3回、4,800万円超で年11回 |
| 源泉所得税 | 翌月10日（納期の特例: 7月10日・翌年1月20日） |
| 住民税の特別徴収 | 翌月10日（納期の特例: 12月10日・6月10日） |
| 法定調書・給与支払報告書・償却資産申告 | 1月31日 |
| 労働保険の年度更新 | 6月1日〜7月10日 |
| 算定基礎届 | 7月1日〜7月10日 |

## 延滞税の割合（国税）

| 期間 | 2026年 | 2022〜2025年 |
| :--- | ---: | ---: |
| 納期限の翌日から2か月を経過する日まで | 年2.8% | 年2.4% |
| それ以後 | 年9.1% | 年8.7% |
