# 社会保険料の計算方法（令和8年度）— 健康保険・介護保険・子ども・子育て支援金・厚生年金・雇用保険

**要点**

- 健康保険・厚生年金は**標準報酬月額 × 料率**を**労使で折半**。雇用保険だけは**実際の賃金 × 料率**
- 協会けんぽの健康保険料率は都道府県別（令和8年度 9.21%〜10.55%、**2026年3月分から**）。40歳以上65歳未満は**介護保険料 1.62%**
- **子ども・子育て支援金は2026年4月分から**（協会けんぽ 0.23%・労使折半）。事業主のみ負担の子ども・子育て拠出金（0.36%）とは別
- 厚生年金 **18.3%**（標準報酬月額の上限65万円）。雇用保険（一般の事業）は労働者 **0.5%**・事業主 0.85%（2026年4月1日以後に締日がある賃金から）

## 料率（令和8年度）

| 保険 | 料率（労使合計） | 従業員負担 |
| :--- | :--- | :--- |
| 健康保険（協会けんぽ） | 都道府県別（東京都 9.85%・大阪府 10.13% など） | 半分 |
| 介護保険（40歳以上65歳未満） | 1.62% | 半分 |
| 子ども・子育て支援金（2026年4月分〜） | 0.23% | 半分 |
| 厚生年金保険 | 18.3% | 半分 |
| 雇用保険（一般の事業） | 1.35% | 0.5% |
| 子ども・子育て拠出金 | 0.36% | なし（事業主のみ） |
