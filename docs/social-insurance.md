# 社会保険料の計算方法（令和8年度）— 健康保険・介護保険・子ども・子育て支援金・厚生年金・雇用保険

**要点**

- 健康保険・厚生年金の保険料は、実際の給与ではなく**標準報酬月額 × 保険料率**で計算し、**労使で折半**する
- 協会けんぽの健康保険料率は**都道府県ごと**（令和8年度は 9.21%〜10.55%）。40歳以上65歳未満は**介護保険料 1.62%** が加わる
- **2026年4月分から、子ども・子育て支援金（0.23%・労使折半）** が健康保険料と一緒に徴収される
- 厚生年金保険料率は **18.3%**（固定）。雇用保険は標準報酬ではなく**実際の賃金 × 料率**（令和8年度 労働者 0.5%）

## 標準報酬月額

報酬月額（基本給・諸手当・通勤手当などの合計）を等級の表に当てはめて決めます。例:

| 報酬月額 | 標準報酬月額 |
| :--- | ---: |
| 270,000円以上 290,000円未満 | 280,000円 |
| 290,000円以上 310,000円未満 | 300,000円 |
| 310,000円以上 330,000円未満 | 320,000円 |

- 健康保険は 58,000円（第1級）〜 1,390,000円（第50級）
- 厚生年金は 88,000円〜 **650,000円**（令和7年の年金制度改正で、2027年9月分から 68万円、2028年9月分から 71万円、2029年9月分から 75万円に段階的に引上げ）
- 原則として毎年4〜6月の報酬で決め（算定基礎届・7月1日〜7月10日に提出）、9月分から1年間使う。大きく変わったときは随時改定（月額変更届）

## 保険料率（令和8年度）

| 保険 | 料率（労使合計） | 従業員負担 |
| :--- | :--- | :--- |
| 健康保険（協会けんぽ） | 都道府県別（東京都 9.85%・大阪府 10.13% など） | 半分 |
| 介護保険（40歳以上65歳未満） | 1.62% | 半分 |
| 子ども・子育て支援金（2026年4月分〜） | 0.23% | 半分 |
| 厚生年金保険 | 18.3% | 半分 |
| 雇用保険（一般の事業） | 1.35% | 0.5%（事業主 0.85%） |
| 子ども・子育て拠出金 | 0.36% | なし（事業主のみ） |

協会けんぽの令和8年度の料率は2026年3月分（4月納付分）から、雇用保険の令和8年度の料率は2026年4月1日以後に締日がある賃金から使います。

## 例: 月給30万円（標準報酬月額 30万円）

計算式: 従業員負担 = 標準報酬月額 × 料率 ÷ 2（雇用保険は 賃金 × 0.5%）

| 従業員負担 | 東京都・30歳 | 東京都・45歳 | 大阪府・30歳 |
| :--- | ---: | ---: | ---: |
| 健康保険（＋介護） | 14,775円 | 17,205円 | 15,195円 |
| 子ども・子育て支援金 | 345円 | 345円 | 345円 |
| 厚生年金 | 27,450円 | 27,450円 | 27,450円 |
| 雇用保険 | 1,500円 | 1,500円 | 1,500円 |
| **合計** | **44,070円** | **46,500円** | **44,490円** |

東京都・45歳の場合、事業主の負担は 健康保険（＋介護）17,205円・支援金 345円・厚生年金 27,450円・雇用保険 2,550円・子ども・子育て拠出金 1,080円で、合計 **48,630円** です。

## 端数処理と年齢

- 給与から控除する従業員負担の1円未満は、**50銭以下切捨て・50銭超切上げ**（労使で特約があればそれに従う）
- 年齢は「誕生日の前日」に達するので、**誕生日の前日が属する月**から介護保険（40歳）の対象、65歳になる月から介護保険は健康保険と別の徴収（市区町村）に
- 厚生年金は70歳、健康保険は75歳（後期高齢者医療制度へ）で資格を失う
- 保険料は「翌月徴収」（前月分を当月の給与から控除）が一般的

## 健康保険組合の場合

健康保険組合は料率と負担割合（事業主が多く負担することがある）を組合ごとに決めています。組合の保険料額表で、合計の料率と従業員負担の料率を確認して計算します。

## よくある質問

**Q. 子ども・子育て支援金はいつから、いくら引かれますか？**
A. 2026年4月分の保険料から、標準報酬月額 × 0.23% を労使で折半します。標準報酬月額30万円なら従業員負担は345円です。

**Q. 月給30万円の社会保険料（従業員負担）はいくらですか？**
A. 協会けんぽ東京都・40歳未満なら、健康保険・支援金・厚生年金・雇用保険の合計で 44,070円です（令和8年度）。

**Q. 40歳になると、いつから介護保険料がかかりますか？**
A. 40歳の誕生日の前日が属する月の分からです。1日生まれの人は前月分からになります。
