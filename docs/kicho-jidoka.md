# 記帳代行・記帳の自動化 — 税理士事務所の入力業務を AI で減らす方法

**要点**

- 記帳代行は、税理士が税理士業務に付随して行える業務（税理士法 第2条第2項「会計帳簿の記帳の代行」）で、多くの税理士事務所の月次業務の中心です
- 時間がかかるのは「**証憑の回収**」「**手入力**」「**税区分の判定**（インボイス・軽減税率・経過措置）」「**通帳・カード明細との突合**」の4つ
- 自動化の基本は、**証憑を発生した日にデータで集め、AI で仕訳のドラフトを作り、人は「要確認」だけを見る**こと
- 作った仕訳は、弥生・freee・マネーフォワード・TKC などの会計ソフトに **CSV で取り込む**

## 記帳代行の工程と、自動化できるところ

| 工程 | 従来のやり方 | 自動化のやり方 |
| :--- | :--- | :--- |
| 証憑の回収 | 月末・決算前に紙の束を郵送・持参してもらう | 顧問先がスマホで撮って送る／スキャナでまとめて読み取る |
| 入力 | 1枚ずつ日付・取引先・金額を打ち込む | AI が読み取り、勘定科目・税区分・摘要の付いた仕訳ドラフトを作る |
| 税区分 | 8%・10%・登録番号の有無・経過措置を人が判定 | 登録番号と取引日から経過措置（80%・70%控除）まで判定し、迷うものは要確認に |
| 突合 | 通帳・カード明細と紙を見比べる | 銀行明細の出金と請求書を突き合わせ、証憑のない出金・未払いを一覧に |
| 確認 | 紙と画面を見比べて全件チェック | 原本と仕訳を並べ、理由付きの「要確認」だけを確認 |
| 会計ソフトへ | 手入力または転記 | 会計ソフトの取込形式の CSV で一括インポート |

入力と突合の自動化は、[領収書・レシートのAI読み取り](https://shiwake.isz.ai/tools/receipt-ocr/?utm_source=github&utm_medium=referral)・[請求書のAI読み取り](https://shiwake.isz.ai/tools/invoice-ocr/?utm_source=github&utm_medium=referral)・[通帳・銀行明細のAI読み取り](https://shiwake.isz.ai/tools/tsucho-ocr/?utm_source=github&utm_medium=referral)で試せます（無料・登録で証憑100枚まで）。

## 顧問先からの証憑回収

記帳の遅れの多くは、入力ではなく回収で起きます。回収の方法ごとの特徴は次のとおりです。

| 回収の方法 | 良い点 | 注意点 |
| :--- | :--- | :--- |
| 紙の郵送・持参 | 顧問先の手間が少ない | 月末・決算前に集中する。紛失・返却の手間 |
| 事務所でスキャン | 画質をそろえやすい | 紙が届くまで入力できない |
| クラウドストレージの共有フォルダ | 発生した日に送れる | ファイル名・画質がばらばらになりやすい |
| スマホからの提出リンク | アプリ不要で、撮ったその場で送れる | 1枚の写真に何枚も並べて撮ると画質が足りない |

- **電子帳簿保存法のスキャナ保存**では、受領からおおむね7営業日以内（事務処理規程があれば最長2か月とおおむね7営業日以内）の入力が求められます。発生した日に送ってもらう方が、期限に余裕ができます（[スキャナ保存の要件](denchoho.md)）
- メールの PDF や Web の明細は「電子取引」で、**顧問先がデータのまま保存する義務**があります。印刷して渡してもらうのではなく、ファイルのまま送ってもらいます（[電子取引データの保存](denshi-torihiki.md)）
- スマホ撮影は「**書類1枚を画面いっぱいに**」が基本です。A4 を 200dpi 相当で読むには約387万画素が必要です

## 会計ソフトへの CSV 取込（弥生・freee・マネーフォワード・TKC）

主な会計ソフトには、仕訳データを CSV などのファイルで一括で取り込む機能があります。列の並び・文字コード・日付の書き方・税区分の名前はソフトごとに決まっているため、次の点に気をつけます。

- **勘定科目・補助科目・税区分の名前を、取込先の会計ソフトの設定と完全に一致させる**（「仮払消費税等」と「仮払消費税」のような違いでもエラーや別科目になる）
- **経過措置の税区分**（80%控除・70%控除）は、取込先のソフトが用意している区分名に合わせる
- 初回は数件だけ**テスト取込**し、残高と税区分の集計を確認してから全件を取り込む
- **二重取込**を防ぐため、取り込んだ期間・ファイルを記録する
- 原本を探せるように、**摘要や証憑番号に原本との対応**を残す

## 導入の進め方

1. **顧問先を1〜2社選んで試す** — 証憑の多い顧問先ほど効果が分かりやすい
2. **記帳ルールを登録する** — 「この取引先は外注費」「社長のタクシー代は旅費交通費」など、事務所と顧問先ごとのルール
3. **確認の範囲を決める** — 全件を見直すのではなく、AI が理由付きで挙げた要確認（二重計上、1人1万円を超える飲食費、源泉徴収の漏れ候補、資産計上の候補など）を確認する
4. **回収の方法を切り替える** — 紙の束から、発生した日のスマホ提出へ
5. **時間を測る** — 1社あたりの入力・確認の時間を、導入前後で比べる

AI に任せることと人が確認することの分け方は、[AI経理とは](ai-keiri.md)で詳しく説明しています。

## よくある質問

**Q. 記帳代行は税理士でなくてもできますか？**
A. 記帳の代行そのものは税理士の独占業務ではありません。ただし、税務書類の作成や税務相談は税理士業務です。

**Q. AI で作った仕訳は、そのまま申告に使えますか？**
A. AI が作るのは仕訳のドラフトです。科目・税区分の判断と最終確定は、税理士・経理担当者が行います。

**Q. 顧問先がスマホで撮った写真は、電子帳簿保存法の要件を満たしますか？**
A. 書類1枚を画面いっぱいに撮れば、最近のスマホなら解像度は足ります。入力期限・訂正削除の履歴・検索など、他の要件も満たす仕組みで保存する必要があります。

**Q. 会計ソフトを変えずに使えますか？**
A. ISZ™ 仕訳AI は、弥生会計・freee会計・マネーフォワード クラウド会計・TKC（FX シリーズ）・JDL・勘定奉行の取込形式で CSV を出力するため、今の会計ソフトのまま使えます。
