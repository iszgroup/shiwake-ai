# 電子取引データの保存方法（電子帳簿保存法）— メールのPDF・Web明細の保存義務、検索要件、猶予措置

→ **完全版（計算例・よくある質問・出典付き）: [電子取引データの保存方法 — メールのPDF・Web明細の保存義務、検索要件が不要な場合と猶予措置](https://shiwake.isz.ai/guide/denshi-torihiki/?utm_source=github&utm_medium=referral)**

**要点**

- メール添付の PDF、Web・EC サイトの領収書、クラウドの請求書、EDI、カード・スマホ決済の利用明細データは「**電子取引**」。**2024年1月1日以後は電子データのまま保存**する義務がある（印刷した紙だけの保存は不可）
- 要件は **改ざん防止（4つの方法のいずれか）・見読性・検索**。小さな会社は**事務処理規程**（国税庁のひな形あり）と、ファイル名「日付_取引先_金額」または索引簿で対応できる
- ダウンロードの求めに応じられれば、**基準期間の売上高5,000万円以下**（非課税売上を含む「売上高」で判定）か、**出力書面を日付・取引先ごとに整理して提示できる**場合は検索要件がすべて不要
- **猶予措置**：相当の理由があり、データのダウンロードと出力書面の提示・提出に応じられれば要件にかかわらず保存できる（届出不要）。ただし**データそのものの保存は必要**

## 改ざん防止の措置（次のいずれか）

| 方法 | 内容 |
| :--- | :--- |
| 1 | タイムスタンプが付いたデータを受け取る |
| 2 | 受け取った側が速やか（おおむね7営業日以内）にタイムスタンプを付す（規程があれば最長2か月＋7営業日以内） |
| 3 | 訂正削除の履歴が残る、または訂正削除できないシステムで受け取り・保存する |
| 4 | 正当な理由がない訂正及び削除の防止に関する事務処理規程を定め、運用し、備え付ける |

## 検索要件

| 場合 | 必要な検索 |
| :--- | :--- |
| 原則 | 日付・金額・取引先で検索、日付・金額の範囲指定、2項目以上の組合せ |
| ダウンロードの求めに応じられる | 日付・金額・取引先で検索（範囲指定・組合せは不要） |
| 上に加えて、売上高5,000万円以下、または出力書面を日付・取引先ごとに整理して提示できる | 不要 |
