# 電子取引データの保存方法（電子帳簿保存法）— メールのPDF・Web明細の保存義務、検索要件、猶予措置

**要点**

- メールで受け取った PDF の請求書、Web からダウンロードした領収書、クラウドサービスの請求データなどは「**電子取引**」で、**2024年1月1日以後は電子データのまま保存**する義務がある（印刷した紙だけの保存は不可）
- 保存の要件は「**改ざん防止の措置**」「**見読性**（ディスプレイ・プリンタ等）」「**検索機能**」の3つ
- 検索は **取引年月日・取引金額・取引先**。基準期間の売上高が **5,000万円以下**で、税務職員の**ダウンロードの求め**に応じられれば検索要件は不要
- 要件どおりに保存できない**相当の理由**があり、ダウンロードの求めと**出力書面の提示・提出**に応じられれば、要件にかかわらず保存できる（**猶予措置**・事前申請不要）

## 電子取引にあたるもの

| 例 | 保存するもの |
| :--- | :--- |
| メールに添付された請求書・領収書の PDF | PDF ファイル（本文に取引内容があればメール本文も） |
| EC サイト・Web サービスからダウンロードした領収書 | ダウンロードした PDF、または画面の取引データ |
| クラウドの請求書サービス・電子契約サービス | 受け取った請求書・契約書のデータ |
| EDI 取引、ペーパーレス FAX | 受信したデータ |
| クレジットカード・交通系 IC・スマホ決済の利用明細データ | 利用明細のデータ |

紙で受け取った書類をスキャンして保存する「[スキャナ保存](denchoho.md)」とは別の制度です。

## 保存の要件

### 1. 改ざん防止の措置（次のいずれか）

1. タイムスタンプが付いたデータを受け取る
2. 受け取った後、速やかに（おおむね7営業日以内）タイムスタンプを付す。事務処理の期間を規程で定めていれば、その期間（最長約2か月）の経過後、速やかに（おおむね7営業日以内）付す
3. 訂正・削除の履歴が残る、または訂正・削除ができないシステムで受け取り・保存する
4. 「不当な訂正削除の防止に関する事務処理規程」を定めて守る

小規模な事業者では、4の事務処理規程を定める方法がよく使われます（国税庁がひな形を公表しています）。

### 2. 見読性

ディスプレイ・プリンタとその操作説明書を備え付け、画面・書面に整然とした形式で速やかに出力できるようにします。自社開発のシステムを使う場合は、システムの概要を記載した書類も備え付けます。

### 3. 検索機能

| 原則 | 内容 |
| :--- | :--- |
| 検索項目 | 取引年月日・取引金額・取引先 |
| 範囲指定 | 日付と金額は範囲を指定して検索できる |
| 組合せ | 2つ以上の項目を組み合わせて検索できる |

- 税務職員のダウンロードの求めに応じられれば、**範囲指定・組合せは不要**
- 次のどちらかに当たり、ダウンロードの求めに応じられれば、**検索要件はすべて不要**
  - 基準期間（2年前の年・2事業年度前）の売上高が**5,000万円以下**（令和5年度改正前は1,000万円以下）
  - 出力した書面を、**取引年月日その他の日付と取引先ごとに整理**して提示・提出できる

専用のシステムがない場合は、ファイル名を「**取引年月日_取引先_金額**」の規則で付けてフォルダで管理する方法や、索引簿（一覧表）を作る方法でも検索要件を満たせます。

## 猶予措置（2024年1月から）

次の両方を満たせば、上の保存要件にかかわらず、電子取引データをそのまま保存するだけでよいとされています。事前の申請や届出は不要です。

- 保存要件に従って保存できなかったことについて、**所轄税務署長が相当の理由があると認める**（システムの整備が間に合わない、人手不足、資金不足など）
- 税務調査などで、**データのダウンロードの求め**と、**出力書面の提示・提出の求め**に応じられる

システムが整っているのに特段の事情なく要件どおりに保存していない場合は、猶予措置の対象になりません。なお、2023年12月31日までの電子取引は、宥恕措置により出力書面での保存が認められていました。

## 守らないとどうなるか

- 電子取引データを保存していない場合、青色申告の承認の取消しの対象になり得ます
- 電子取引データやスキャナ保存のデータに関して隠蔽・仮装があった場合、**重加算税が10%加重**されます
- 保存期間は法人税法の帳簿書類と同じで、原則として**7年**（欠損金が生じた事業年度は10年）

## よくある質問

**Q. メールで届いた PDF の請求書は、印刷して保存すればよいですか？**
A. 2024年1月1日以後の電子取引は、PDF のまま保存する必要があります。印刷した紙は補助として保存できますが、紙だけでは要件を満たしません。

**Q. 小さな会社でも検索機能のあるシステムが必要ですか？**
A. 基準期間の売上高が5,000万円以下で、ダウンロードの求めに応じられれば検索要件は不要です。改ざん防止は事務処理規程で対応できます。

**Q. 猶予措置を使うには届出が必要ですか？**
A. 不要です。相当の理由があり、ダウンロードの求めと出力書面の提示・提出に応じられれば対象になります。
