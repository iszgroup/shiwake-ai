# 源泉徴収税額の計算方法（2026年・令和8年分）— 給与・賞与・報酬（10.21%）

**要点**

- 給与の源泉徴収税額は、**社会保険料等を控除した後の給与の金額**と**扶養親族等の数**で、国税庁の「源泉徴収税額表（月額表）」から求める
- 扶養控除等申告書を出している人は**甲欄**、出していない人（2か所目の給与など）は**乙欄**
- 月額表の **740,000円以上**は、表の算式「**区切りの金額の税額 ＋ 区切りを超える金額 × ◯%**」で計算する
- 扶養親族等が**7人を超える**ときは、**7人の税額から1人ごとに1,610円**を控除する
- 税額表の代わりに**電算機計算の特例**の算式も使える（年の途中で変えない）
- 報酬・料金は **100万円以下 10.21%、100万円を超える部分 20.42%**（復興特別所得税を含む）

## 給与の源泉徴収税額（月額表・甲欄）

### 740,000円未満: 表から引く

| 社会保険料等控除後の給与（令和8年分） | 扶養0人 | 扶養1人 | 扶養2人 | 扶養3人 |
| :--- | ---: | ---: | ---: | ---: |
| 299,000円以上 302,000円未満 | 7,930円 | 6,320円 | 4,700円 | 3,080円 |

令和7年分の同じ行は 8,420円・6,740円・5,130円・3,510円でした。令和8年分は給与所得控除と基礎控除の引上げで、税額が下がっています。

### 740,000円以上: 表の算式で計算する（令和8年分）

| 社会保険料等控除後の給与 | 税額（扶養0人） |
| :--- | :--- |
| 740,000円以上 790,000円未満 | 71,680円 ＋ 740,000円を超える金額 × 20.42% |
| 790,000円以上 960,000円未満 | 81,890円 ＋ 790,000円を超える金額 × 23.483% |
| 960,000円以上 1,710,000円未満 | 121,820円 ＋ 960,000円を超える金額 × 33.693% |
| 1,710,000円以上 2,130,000円未満 | 374,520円 ＋ 1,710,000円を超える金額 × 40.84% |
| 2,130,000円以上 2,170,000円未満 | 549,440円 ＋ 2,130,000円を超える金額 × 40.84% |
| 2,170,000円以上 2,210,000円未満 | 571,220円 ＋ 2,170,000円を超える金額 × 40.84% |
| 2,210,000円以上 2,250,000円未満 | 593,000円 ＋ 2,210,000円を超える金額 × 40.84% |
| 2,250,000円以上 3,500,000円未満 | 614,770円 ＋ 2,250,000円を超える金額 × 40.84% |
| 3,500,000円以上 | 1,125,270円 ＋ 3,500,000円を超える金額 × 45.945% |

区切りの税額は扶養親族等の数ごとに決まっています（例: 740,000円の行は扶養1人 65,210円、2人 58,750円）。

**例1**: 社会保険料等控除後 1,063,741円・扶養0人（令和8年分）
→ 121,820円 ＋（1,063,741円 − 960,000円）× 33.693% = 121,820円 ＋ 34,953円 = **156,773円**

**例2**: 社会保険料等控除後 800,000円・扶養9人（令和8年分）
→ 7人の税額 36,620円 ＋ 10,000円 × 23.483% = 38,968円、7人を超える2人分 3,220円を控除して **35,748円**

740,000円以上の部分を電算機計算の特例の算式で代用すると、税額表と数十円〜数百円ずれることがあります。税額表で計算すると決めているなら、740,000円以上も表の算式を使います。

乙欄も 740,000円以上は表の算式で計算し、従たる給与についての扶養控除等申告書が出ていれば扶養親族等1人ごとに1,610円を控除します。

## 電算機計算の特例（令和8年分）

社会保険料等控除後の給与等の金額を A とすると:

1. **給与所得控除（第1表）**: A ≦ 158,333円 → 54,167円／〜299,999円 → A×30%＋6,667円／〜549,999円 → A×20%＋36,667円／〜708,330円 → A×10%＋91,667円／それ以上 → 162,500円（1円未満切上げ）
2. **基礎控除（第3表）**: A ≦ 2,120,833円 → 48,334円（以降、段階的に減少）
3. **配偶者・扶養控除（第2表）**: 扶養親族等の数 × 31,667円
4. **課税給与所得金額 B** = A − 1 − 2 − 3
5. **税額（第4表）**: B ≦ 162,500円 → B×5.105%／〜275,000円 → B×10.21%−8,296円／〜579,166円 → B×20.42%−36,374円／〜750,000円 → B×23.483%−54,113円／〜1,500,000円 → B×33.693%−130,688円／〜3,333,333円 → B×40.84%−237,893円／それ以上 → B×45.945%−408,061円（**10円未満四捨五入**）

例: A = 300,000円・扶養0人 → 給与所得控除 96,667円、基礎控除 48,334円、B = 154,999円 → 154,999円 × 5.105% ≒ 7,912円 → **7,910円**（月額表では 7,930円）

## 賞与

賞与の源泉徴収税額 =（賞与 − 社会保険料）× **算出率**

算出率は「賞与に対する源泉徴収税額の算出率の表」で、**前月の社会保険料等控除後の給与**と扶養親族等の数から決まります。

例: 前月の給与（社会保険料控除後）30万円・扶養0人 → 算出率 6.126%。賞与（社会保険料控除後）50万円 → 500,000円 × 6.126% = **30,630円**

前月に給与がない場合や、賞与が前月の給与の10倍を超える場合は、月額表を使った別の計算になります。

## 報酬・料金（原稿料・デザイン料・講演料・税理士報酬など）

| 1回の支払金額 | 源泉徴収税額 |
| :--- | :--- |
| 100万円以下 | 支払金額 × **10.21%** |
| 100万円超 | （支払金額 − 100万円）× **20.42%** ＋ 102,100円 |

- 請求書で消費税額が区分されていれば、**税抜の金額**だけを対象にできる
- 司法書士・土地家屋調査士の報酬は1回の支払金額から1万円を引いてから10.21%、外交員報酬・ホステス等の報酬は計算が異なる
- 個人に支払う場合が対象（法人への支払は原則として源泉徴収しない）

例: デザイン料 10万円（税抜）→ **10,210円**を源泉徴収し、89,790円（＋消費税）を支払う

**手取り額で契約した場合（グロスアップ）**: 100万円以下なら 支払金額 ≒ 手取り ÷ 0.8979。例: 手取り 89,790円 → 99,999円（99,999円 − 源泉徴収 10,209円 = 89,790円。税額の1円未満は切捨て）

## 納付

源泉徴収した税額は、原則として**支払った月の翌月10日**までに納付します。給与の支給人員が常時10人未満の事業者は、届出により**半年ごと（7月10日・翌年1月20日）**の納付にできます（納期の特例）。期限の一覧は[法人の申告・納付期限](shinkoku-kigen.md)にまとめています。

## よくある質問

**Q. 月給が74万円を超えると、源泉徴収税額はどう計算しますか？**
A. 月額表の「740,000円以上」の欄にある算式で計算します。例えば令和8年分・扶養0人で 960,000円以上 1,710,000円未満なら、121,820円 ＋ 960,000円を超える金額 × 33.693% です。

**Q. 扶養親族等が8人以上いるときは？**
A. 7人の欄の税額から、7人を超える1人ごとに1,610円を控除します。

**Q. 税額表と電算機計算の特例は、どちらを使ってもよいですか？**
A. どちらも認められていますが、年の途中で変えないようにします。差は通常数十円程度です。
