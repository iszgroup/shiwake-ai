# 源泉徴収税額の計算方法（2026年・令和8年分）— 給与の月額表・賞与・報酬（10.21%）・退職金

→ **完全版（計算例・よくある質問・出典付き）: [源泉徴収税額の計算方法（令和8年分）— 給与の月額表・賞与・報酬・退職金](https://shiwake.isz.ai/guide/gensen-choshu/?utm_source=github&utm_medium=referral)**

**要点**

- 給与は**社会保険料等を控除した後の給与**と**扶養親族等の数**で、国税庁の月額表を引く。扶養控除等申告書を出している人は**甲欄**、出していない人は**乙欄**
- 月額表の **740,000円以上**は表の算式（区切りの税額 ＋ 超える金額 × ◯%）。扶養親族等が**7人を超える**と1人ごとに**1,610円**を控除
- 賞与 =（賞与 − 社会保険料等）× **算出率**。**乙欄も一律30.63%ではなく**、前月の給与で 10.21%〜45.945% の5段階。前月の給与がない・賞与が前月の給与の10倍超なら月額表を使う（÷6、計算期間6か月超は÷12）
- 報酬・料金は **100万円以下 10.21%、超える部分 20.42%**。請求書で消費税が区分されていれば税抜で計算できる
- 納付は**翌月10日**。給与の支給人員が常時10人未満なら納期の特例で**7月10日・翌年1月20日**（デザイン料・原稿料などは対象外）
